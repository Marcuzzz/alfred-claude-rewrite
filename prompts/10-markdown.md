---
title: Clean up Markdown
subtitle: Tidy formatting, improve wording, fix the heading structure
markdown: true
---

The text is Markdown. Clean it up and improve it.

- Fix spelling and grammar and tighten unclear wording, keeping the meaning.
- Make the formatting consistent: ATX headings (#), one list marker style, blank lines around headings, lists, tables and code blocks, no trailing whitespace, no runs of empty lines.
- Then judge the heading structure: add headings where long stretches of text cover several topics without one, merge or remove headings over sections of only a sentence or two, make sibling headings parallel in wording, and fix skipped levels (for example # followed by ###).
- Use at most one top-level heading, and do not add one if the text is a fragment that starts at a deeper level.
- Leave code blocks, inline code, URLs, link targets, front matter and HTML exactly as they are.
